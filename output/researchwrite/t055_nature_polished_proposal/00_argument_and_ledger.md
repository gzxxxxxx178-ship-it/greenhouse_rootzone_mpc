# 核心论证与术语表

## 一句话论证

面向水肥一体机在通信与传感异常并发条件下的EC闭环连续控制问题，本研究拟构建物联网与边云协同管控系统，以通信风险和观测风险驱动云端预测、边缘控制与模型锚定降级之间的控制权切换，并通过配对仿真和MQTT软件在环评价其跟踪性能、切换平滑性与适用边界。

## 术语表

| 规范术语 | 首次定义 | 统一写法 |
|---|---|---|
| 电导率（EC） | electrical conductivity（EC） | 后文统一使用“EC” |
| 风险感知自适应边云监督控制（RA-ECSC） | risk-aware adaptive edge-cloud supervisory control | 后文统一使用“RA-ECSC” |
| 通信风险 | 由命令年龄、时延EWMA和窗口丢包率构成 | 记为 `R_net` |
| 观测风险 | 由双EC传感器差异和模型残差构成 | 记为 `R_obs` |
| M0 | 云端预测模式 | 统一写作“M0云端预测模式” |
| M1 | 边缘控制模式 | 统一写作“M1边缘控制模式” |
| M2 | 模型锚定降级模式 | 统一写作“M2模型锚定降级模式” |
| MQTT软件在环 | 基于MQTT跨进程消息链的软件在环验证 | 不与实体台架验证混用 |
