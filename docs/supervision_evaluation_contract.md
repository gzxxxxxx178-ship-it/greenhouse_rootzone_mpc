# 可信监督锁定评价契约

## 方法

- `base_mpc`：求解失败时保持上一命令，缺测时保持最近观测，不使用回退状态机。
- `fixed_fallback`：只根据观测有效、求解成功和反馈一致等离散标志切换，不使用连续风险量，标志恢复后立即返回MPC。
- `trustworthy_supervision`：使用观测、模型、执行风险与离散标志，通过滞回、驻留和恢复确认分配MPC、规则回退及安全暂停。

三种方法共享冻结MPC、冻结规则、对象、扰动、噪声和异常日程。

## 主要评价量

- 异常开始至异常结束后48步的水分亏缺积分。
- 全程水分亏缺积分和仿真灌水命令量。
- 安全边界违反场景和持续步数。
- 动作变化次数。
- MPC、规则回退和安全暂停占用率。
- 首次检测延迟、恢复时间和正常场景非MPC占用率。

## 预设成功门

相对基础MPC，可信监督只有同时满足以下条件才分类为机制价值获支持：

1. 至少2类异常的事件窗口亏缺积分配对中位差小于−0.000001；
2. 事件窗口亏缺积分配对中位差大于+0.000001的异常类型不超过2类；
3. 不增加安全边界违反场景数；
4. 正常场景非MPC模式占用率中位数不超过10%。

若只满足部分条件，分类为`PARTIAL_MECHANISM_VALUE_WITH_BOUNDARIES`；如果没有异常类型改善或增加安全违反，分类为`SUPERVISION_VALUE_NOT_SUPPORTED`。

## 证据边界

- 异常类型、幅值和时序是确定性软件压力日程。
- 异常标签只用于评价，不提供给控制器或监督器。
- 实际未来蒸散、虚拟对象参数和真实土壤水分不提供给在线算法。
- 结果不证明实体传感器、泵阀或红壤现场性能。
