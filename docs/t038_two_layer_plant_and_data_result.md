# T038 独立双层对象与辨识数据结果

## 判定

独立双层非线性对象、15 min现场格式数据生成器、质量检查和信息准入均已通过软件验收。正式数据包含873行观测、6个辨识循环和3个冻结验证循环；576个辨识转移全部可用，设计矩阵秩为5。

最弱层的幅值敏感最小奇异值为133.715，高于冻结参考线28.0；合并预测归一化标准误为0.004745，低于参考线0.018。准入结果为`provisional_ready_for_identification`，因此下一任务可以执行双层模型拟合。

## 对象独立性与守恒

虚拟对象以浅、深层储水量为状态，包含命令—实际灌水效率、旁路入渗、分层水分胁迫蒸散、双向梯度交换、浅层超田间持水量通量、深层非线性排水、过程噪声和测量噪声。对象模块没有导入双层灰箱模型或辨识结果。

生成过程的最大绝对总水量平衡残差小于10⁻¹² mm。命令灌水和实际灌水分别记录，流量积分、实际水深换算与累计水量表保持一致。相同协议和代码提交连续生成的数据、质量报告和准入报告哈希一致。

## 激励设计说明

最初的天气日程使太阳辐射与VPD接近完全相关，无法满足信息准入。正式生成前将VPD相位和云量波动独立化，并保持质量和信息阈值不变。正式设计中太阳辐射与VPD设计列相关系数约为0.217，因而模型能够分离两类气象响应。

这一调整属于采样设计改进：它改变输入覆盖，没有降低最小信息量28.0或最大预测标准误0.018的准入线，也没有使用任何闭环锁定场景。
