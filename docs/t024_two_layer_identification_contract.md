# T024 双层根区灰箱模型辨识与独立验证协议

## 任务性质

本任务建立未来红壤观测数据的模型辨识入口。首次运行使用T023合成样例数据，只评价数据划分、参数估计、预测和报告链路能否执行。无论指标多高，都不能写成红壤模型准确性或MPC现场适用性证据。

## 冻结数据划分

- 只使用`dataset_role=identification`的3个循环估计参数。
- `dataset_role=validation`的2个循环只在参数固定后评价。
- 数据按“场地＋分区＋循环”分组，任何状态转移不得跨越循环边界。
- 时间戳表示采样区间结束时刻，因此从时刻k预测k+1时，使用k时刻状态与k+1行记录的区间灌水量和气象量。
- 运行前必须先通过T023全部现场数据质量闸门。

## 冻结模型

状态为10 cm和25 cm体积含水率。两个状态增量分别采用同一组输入：

```text
Δθ10 = a10(θ10 − θ25) + b10 I + c10 R + d10 VPD + e10
Δθ25 = a25(θ10 − θ25) + b25 I + c25 R + d25 VPD + e25
```

其中，`I`为区间实际灌水深，`R`为太阳辐射除以1000后的量，`VPD`为根据棚内温度和相对湿度计算的水汽压亏缺代理量。参数符号边界在`configs/two_layer_identification_v1.yaml`中冻结：浅层向深层的含水率梯度项使浅层增量系数不大于0、深层增量系数不小于0；灌水响应不小于0；辐射和VPD损失响应不大于0。

该结构是用于控制的低阶灰箱模型，不等同于Richards方程或经土壤水力参数标定的数字孪生。截距允许吸收当前未显式记录的平均蒸散和边界通量，但会降低跨季节外推能力。

## 参数估计

对两个状态增量分别执行有边界最小二乘。实现采用确定性的循环坐标下降，并报告是否收敛、迭代次数和最终参数。当前只拟合一个预先定义的模型结构，不使用验证循环比较候选结构、选择特征、调节边界或改变判据。

## 冻结评价

验证循环同时计算：

1. 单步预测：每一步使用实测当前状态。基线为持久性预测，即下一步等于当前实测值。
2. 整循环滚动预测：每个验证循环只在起点使用一次实测状态，随后递推。基线为整个循环保持初始状态不变。

两个深度分别报告样本数、RMSE、MAE、偏差、基线RMSE和相对基线技能值`1 − RMSE模型/RMSE基线`。

合成烟雾试验只有同时满足以下条件才记为链路通过：

- 质量闸门通过，且辨识循环与验证循环无交集；
- 两个有界求解均收敛，所有参数位于冻结边界内；
- 两个深度的单步技能值均不低于0.10；
- 两个深度的整循环滚动技能值均不低于0；
- 两个深度的整循环绝对偏差均不超过0.01 m³/m³；
- 所有滚动预测位于0.02至0.65 m³/m³。

失败时必须保留失败结果，不得读取验证循环后修改模型或阈值并仍称为独立验证。需要修改时，应建立新的开发数据和新的保留验证循环。

## 输出与结论边界

正式结果写入`data/processed/two_layer_identification_smoke_v1.json`，验证循环预测明细写入`outputs/tables/two_layer_validation_predictions_v1.csv`。结果记录输入文件、冻结配置和运行代码提交号。

合成数据中的循环共享同一种人为生成规律，因此循环分离只能检查程序是否遵守数据角色，不能提供独立生物重复或现场泛化证据。只有未来真实数据通过质量闸门、模型仅在辨识循环拟合并在预留循环达到预先登记指标后，R003才可能从`missing`进入可评价状态。
