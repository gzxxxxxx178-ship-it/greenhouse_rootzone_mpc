# T026 幅值敏感信息量与参数不确定性验证协议

## 研究问题

T025显示充分激励可降低参数恢复误差，但逐列标准化条件数没有改善。该指标删除了各特征的幅值与跨度，不能回答采集信号相对于噪声是否足够强。T026在新的30个配对种子上检验：按参数允许范围无量纲化、按差分观测噪声缩放的信息矩阵，能否随弱、中、强三档激励单调改善，并预警实际参数恢复误差。

T026是新的冻结试验，不追溯修改T025的判据或失败分类。

## 冻结设计

模型结构、真实参数、参数边界、单循环48步、3个辨识循环和共同探针沿用T025。三个条件在同一随机种子下共享完全相同的过程与测量噪声数组，仅改变初始水分、灌水脉冲及天气输入。中等激励在首次正式运行前加入，使评价包含弱、中、强三级，而非只比较两个端点。

随机种子固定为26001至26030，与T025的种子不重叠。种子只代表仿真噪声重复，不是现场独立重复。

## 信息量和不确定性

对每层回归设计矩阵 `X`，用该层参数上下界宽度组成对角矩阵 `D`。定义无量纲且保留幅值的矩阵 `Z = XD / sigma_delta`，其中 `sigma_delta = sqrt(2 sigma_measurement^2 + sigma_process^2)`。分别计算两层后，取两层最小奇异值中的较小值，表示最弱可辨识参数方向的信噪信息量；数值越大越好。

由 `(ZᵀZ)^+` 的对角线计算预测归一化标准误，先在每层5个参数内取均方根，再合并两层。该解析量假设模型结构正确、输入无误差且差分噪声独立；由于相邻差分共享观测且状态进入设计矩阵，其绝对数值只是近似风险指标。

实际恢复证据包括10个参数的归一化RMSE、30次估计的系数经验变异及共同无噪声探针RMSE。预测不确定性与参数RMSE的关联使用90个条件—种子点的秩相关，不作为显著性检验。

## 预设成功判据

正式结果必须同时满足：

- 真实参数严格位于边界内部，90次拟合全部收敛；
- 强/弱信息量中位数比至少1.50；
- 强/弱预测不确定性中位数比不高于0.70；
- 至少80%的种子满足信息量和预测不确定性的弱—中—强严格单调次序；
- 预测不确定性与实际参数RMSE的合并Spearman秩相关至少0.60；
- 强/弱实际参数RMSE中位数比不高于0.65，且至少70%的种子满足实际误差严格单调下降；
- 强/弱参数经验变异比不高于0.70；
- 强/弱共同探针RMSE中位数比不高于0.80。

首次正式结果无论通过或失败均保留，禁止查看结果后改阈值仍称为本试验。

## 证据边界

即使通过，结果也只支持在已知结构、已知噪声和准确输入的合成条件下，用该信息指标辅助设计辨识采样。它不能证明3个现场循环足够，也不能替代红壤传感校准、实测参数辨识和独立真实数据回放。
