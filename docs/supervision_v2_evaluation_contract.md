# 监督V2独立锁定评价契约

## 比较方法

- 基础MPC：异常时不使用监督回退。
- V1可信监督：使用受观测影响的规则回退和安全暂停。
- V2可信监督：观测不可信时拒绝校正状态估计，以模型、蒸散估计和可信执行反馈递推，并由估计下界驱动回退。

三种方法共享冻结MPC、虚拟对象、扰动、噪声和异常日程。V2使用T016冻结的V2C005。确认试验使用144个从未参与开发的新锁定场景，每类异常12个。

## 预设成功门

只有同时满足以下条件，V2才分类为独立确认支持：

1. 在V1此前失败的6类异常中，至少4类的事件窗口亏缺积分配对中位差小于−0.000001；
2. 相对基础MPC，11类非正常异常中事件窗口亏缺积分恶化的不超过2类；
3. 正常场景非MPC占比中位数不超过12%；
4. 相对基础MPC的逐场景灌水相对增量中位数不超过15%；
5. 安全边界违反场景数不高于基础MPC和V1。

若至少改善1个目标异常且未增加安全违反，但未通过全部条件，分类为`V2_PARTIAL_VALUE_WITH_BOUNDARIES`；否则分类为`V2_VALUE_NOT_SUPPORTED`。

## 证据边界

结果只适用于独立的模型仿真与软件故障注入。阀门完全卡滞属于物理不可达工况，评价的是识别和故障后恢复，不能据此主张软件能恢复卡滞期间的供水。现场适用性仍需要红壤参数辨识、传感器数据和泵阀试验。
