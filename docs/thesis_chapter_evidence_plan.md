# 毕业论文章节—主张—证据计划

## 论文定位

建议题名继续使用：**面向红壤设施大棚的智慧管控平台与根区水分MPC适用性研究**。

论文主线不是宣称MPC全面替代规则控制，而是解决一个更符合现有条件的问题：在现场数据有限、模型不确定和执行链可能异常的条件下，如何判断根区MPC何时可用、如何评价其水分控制权衡，并把算法以可追溯方式接入智慧管控平台。

核心贡献可压缩为一句话：**建立从数据准入、模型辨识、冻结控制评价、异常失效分析到平台审计的完整证据链，使有限数据条件下的MPC适用性能够被检验、拒绝和追溯。**

## 章节逻辑

### 第1章 绪论：提出问题

从设施根区控制对模型和反馈质量的依赖切入，指出“采到数据”不等于“数据足以辨识模型”，仿真中的最优控制结果也不自动等于现场可用。由此提出三个研究问题：有限数据何时准入、MPC何时形成可接受权衡、算法怎样进入可审计平台。

本章不把小论文是否发表作为研究成立条件。可迁移的是冻结评价、风险状态和软件审计方法，不能迁移小论文对象参数与有效性结论。

### 第2章 系统需求与总体架构：建立统一对象

定义单分区、双深度根区水分控制对象及平台边界。平台包含数据接入、质量与信息准入、模型版本、规则与MPC服务、监督状态机、命令反馈和审计存储。章节的目标是说明后续算法实验怎样落入同一工程链，不展开尚未验证的硬件性能。

### 第3章 数据准入与双层模型：形成方法创新中心

先给出双深度水分、逐次灌水、流量和棚内气象的最低数据结构，再说明3个辨识循环与2个验证循环只是用途隔离的入口条件。真正的准入由结构质量、幅值敏感信息量、预测不确定性和独立循环验证共同决定。

T024证明辨识与独立验证链路可执行；T025保留原判据失败，用来说明标准化条件数会丢失激励幅值信息；T026给出幅值敏感信息量的替代依据；T027把它变成补采或准入决策；T030至T032补上标定、时间对齐和误差分解。T032应作为方法有效性的例子：面对不相容噪声尺度，流程拒绝输出伪过程噪声参数。

### 第4章 双层规则与MPC冻结对照：回答适用性

以强规则为工程基线，用开发集选参、锁定集确认和场景级配对统计控制结论自由度。主结果采用T041双层集成链：MPC命令灌水配对中位减少6.5 mm，加权亏缺配对中位减少0.000314，联合不劣比例为75.56%，正式分类为`JOINT_VALUE_SUPPORTED`；同时动作变化配对中位增加130次。T010单层“节水伴亏缺”结果作为早期对照，说明状态结构和控制接口统一会改变结论，但两项实验不可直接做因果归因。

本章不使用单一综合分数宣布赢家。论文价值来自预先冻结多个终点，并明确当前联合价值只在独立合成对象上成立，现场适用性与执行器动作代价仍需单独验证。

### 第5章 异常监督：解释失效机理

将V1至V3组织为机制检验，不按开发过程写流水账。V1说明风险识别不能保证有效回退；V2揭示观测隔离与恢复通道耦合导致的恢复死锁；V3说明统一预算可以抑制过湿，却可能放大执行异常下的缺水尾部。预设停止规则阻止继续无边界调参。

章节贡献是给出可复核的失效机制和设计约束，不承担证明监督算法已经优于基础MPC的任务。

### 第6章 平台软件在环：完成工程闭环

用任务—版本—命令—反馈—联锁关系证明算法输出能够被追踪。以重复、乱序、超时、异常退出恢复和MQTT断连重连场景检验平台语义。平台结果支持本机软件在环原型，答辩演示应展示任务状态、准入判定、模型版本、控制模式和反馈链。

### 第7章 综合讨论：给出条件触发路线

把论文结论分为已完成的仿真与软件证据、取得同源现场数据后才能验证的红壤模型、具备联锁与人工接管后才能开展的实体控制。讨论重点是信息不足时补采、模型验证失败时缩减结构、真实回放未过门时停在影子控制。

### 第8章 结论：强化贡献

结论集中回收四点：两级数据准入、冻结配对MPC评价、异常回退失效机理、平台可追溯闭环。现场数据不足作为下一阶段触发条件放在展望中，不在结论末尾扩写成对全文价值的否定。
