# T012 管控平台软件在环验证

## 目标与实现

本阶段验证控制任务从算法输出到平台账目的可追溯性。平台使用SQLite保存任务、逐步命令、执行反馈、联锁状态和模式切换，并在每个任务记录冻结控制器与监督配置的SHA-256。选取正常、求解失败和阀门卡滞各1个锁定场景，仅用于检查软件接口与账目一致性，不新增算法性能比较。

## 验证结果

- 3个任务均完成，共1008个控制步。
- 写入1008条命令和1008条反馈，逐步一一对应。
- 写入154条非MPC联锁记录和35条模式切换记录。
- 每步唯一命令、每命令唯一反馈、无孤立记录、安全暂停命令为零、切换数与原始轨迹一致、任务绑定配置版本，6项约束全部通过。
- 正式JSON与任务导出表连续两次运行SHA-256一致。

该结果只说明本地确定性软件在环的记录结构和关联约束可用。它不验证网络延迟、消息乱序、重复投递、进程崩溃恢复、控制器实时截止时间、实体PLC/泵阀协议或现场安全完整性。
