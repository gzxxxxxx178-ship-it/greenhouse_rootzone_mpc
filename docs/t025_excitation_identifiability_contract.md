# T025 双层根区模型激励与可辨识性对照协议

## 研究问题

T024在合成样例上取得较好的预测指标，但25 cm层交换系数达到参数下界0。T025检验这一问题是否可由采集阶段缺少输入和状态变化解释：在模型结构、真实参数、噪声水平和评价探针相同的条件下，改变辨识循环的灌水、初始水分和气象激励，比较参数恢复与域外预测。

本任务属于已知参数仿真机制试验。它可以为现场采集方案提供设计依据，但不能估计红壤参数、现场噪声或具体需要多少天的数据。

## 冻结对象与噪声

数据由与T024辨识结构一致的双层模型生成，10个真实参数全部严格位于估计边界内部。每个循环包含48个15 min转移。辨识观测叠加标准差0.0005 m³/m³的测量噪声和0.0001 m³/m³的过程噪声。

两种条件使用30个预先列出的配对随机种子。每个种子下，弱激励和充分激励使用完全相同的过程与测量噪声数组，使成对差异主要来自采集激励设计。种子代表数值噪声重复，不是生物重复或现场分区重复。

## 两种辨识设计

每种设计均只有3个辨识循环，避免把结论混同为“增加样本数量”的效果。

### 弱激励

- 3个循环使用相同初始浅层/深层含水率0.215/0.225 m³/m³；
- 均在第1步施加2.0 mm灌水；
- 太阳辐射、VPD基线、幅值和相位完全相同。

### 充分激励

- 3个循环使用不同初始状态，覆盖浅层低于、明显高于和接近深层含水率的情况；
- 灌水量、脉冲次数和施加时刻不同，单次脉冲覆盖0.7至2.8 mm；
- 太阳辐射幅值/相位与VPD基线/幅值/相位在循环间变化。

这些数值是为机制辨识设置的仿真激励，不是作物灌水处方。现场采用前必须受作物安全水分范围、灌水系统最小脉冲、土壤入渗能力和排水风险约束。

## 冻结评价

两个设计均使用T024同一个有边界最小二乘求解器。每次重复计算：

1. 标准化设计矩阵条件数。除截距外，各列先中心化并除以标准差；条件数越小表示列相关和数值病态程度越低。
2. 归一化参数RMSE。每个参数误差除以其冻结上下界宽度，再对10个参数求RMSE。
3. 命中估计边界的参数数量。
4. 共同探针整循环RMSE。两种辨识结果都在同一组3个无噪声、多样化探针循环上滚动预测，探针不参与拟合。

每个条件报告30次重复的中位数、25%分位数和75%分位数。条件比较报告“充分激励/弱激励”的中位数比，以及30个配对种子中充分激励更优的比例。这里不进行显著性检验。

## 预设成功判据

充分激励只有同时达到以下8项要求，才判定本版激励设计获得机制支持：

- 真实参数全部严格位于估计边界内部；
- 60次拟合的两个状态求解器全部收敛；
- 标准化条件数中位数不高于弱激励的50%；
- 归一化参数RMSE中位数不高于弱激励的65%；
- 至少80%的配对种子降低参数误差；
- 共同探针平均RMSE中位数不高于弱激励的80%；
- 至少75%的配对种子降低共同探针RMSE；
- 充分激励命中边界数量的中位数为0。

首次结果失败时应保留失败分类。不得查看结果后修改本配置并继续称为同一冻结试验。
