# T032 动态残差与已知误差分解协议

## 目的

本任务建立过程噪声估计前的拒绝式入口。它回答的是：独立验证循环的一步预测残差，在扣除水分传感器测量误差和流量输入误差后，是否还存在可分辨的剩余方差。合成样例仅验证计算和拒绝逻辑，不提供红壤过程噪声参数。

## 冻结输入与隔离规则

- 动态输入：`data/examples/synthetic_field_observations_v1.csv`；
- 模型结果：`data/processed/two_layer_identification_smoke_v1.json`；
- 标定结果：`data/processed/field_calibration_example_v1.json`；
- 只使用角色为`validation`的2个独立循环和94个状态转移；
- `identification`循环不得进入报告残差；
- 每行时间戳表示采样区间结束时刻，状态从前一行转移至当前行时使用当前行记录的灌水、辐射和VPD。

## 方差分解

对每个深度计算独立验证一步残差的去均值样本方差。测量误差同时传播当前时刻的浅、深层观测误差和下一时刻目标观测误差；传播系数取自冻结双层模型的状态梯度系数。流量输入误差按“灌水响应系数×当前区间实际灌水量×标定相对RMSE”逐转移计算，再取均值方差。

剩余量定义为：

`未解释动态方差 = 验证残差方差 − 测量误差方差 − 输入误差方差`

若任一深度的剩余量不大于冻结数值容差，结果必须为`not_estimable_measurement_floor_exceeds_dynamic_residual`，且过程噪声候选保持为空。只有两个深度的剩余量均为正，才输出`unexplained_dynamic_variance_screening_candidate`。

## 解释边界

正的剩余量也不能直接称为真实过程噪声，因为它还包含模型结构偏差、参数估计误差、时间相关误差及未记录输入。现场使用时必须让传感标定、流量标定和动态循环来自同一设备与工况体系，并保留独立验证循环。若标定测量噪声地板高于动态残差，应检查数据尺度、标定代表性和样例一致性，而不是把负方差截断后报告为零过程噪声。
