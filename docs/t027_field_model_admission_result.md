# T027 现场数据模型准入两级闸门结果

## 冻结判定

T027在协议提交`03f304f`后运行，软件工作流状态为`passed`。冻结的240行合成接入样例通过T023基础质量检查，但模型准入决策为`collect_more_excitation`，与预设结果一致。

## 准入结果

| 检查 | 结果 | 判定线 |
|---|---:|---:|
| 辨识循环 | 3 | 至少3个 |
| 可用循环内转移 | 141/141（100%） | 至少120且可用率不低于95% |
| 设计矩阵秩 | 5 | 等于5 |
| 最弱层最小奇异值 | 20.012 | 不低于28.0 |
| 合并预测归一化标准误RMS | 0.02341 | 不高于0.018 |

数据数量、完整性和矩阵秩达到要求，但信息强度与预测不确定性两项失败。三个辨识循环采用几乎相同的初始状态、2 mm灌水脉冲和天气过程，重复记录增加了行数，却没有形成足够的独立输入变化。闸门因此阻止这批数据直接进入参数冻结。

## 补采指令

当前不能仅按“再采几个循环”确定补数数量。下一批辨识循环应在作物安全含水率、系统最小脉冲和土壤入渗能力约束内，优先增加以下变化：

1. 使浅层高于和低于深层的初始水分梯度都出现；
2. 改变实际灌水量、施加时刻和单循环脉冲次数，避免每个循环完全相同；
3. 覆盖不同太阳辐射和VPD过程，同时保持流量、水深和累计表三方核对；
4. 每次新增一个完整循环后重新计算信息量，达到参考线后停止用于辨识的补采，并保留至少2个独立循环只做验证。

不能为了提高信息量而突破作物水分安全范围，也不能把验证循环转为辨识数据。若安全约束下始终达不到参考线，应缩减模型参数、固定弱可辨识参数或改用更强先验，而不是继续无边界采集。

## 证据边界

本结果证明两级软件闸门能区分“数据文件合格”和“辨识信息暂时充分”。28.0和0.018来自T026合成中等激励参考，噪声尺度也尚未由真实传感器重复标定，因此通过时只能输出`provisional_ready_for_identification`。获得实测数据后必须重估噪声并另行冻结现场阈值。
