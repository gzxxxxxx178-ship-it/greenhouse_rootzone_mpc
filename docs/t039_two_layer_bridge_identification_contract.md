# T039 双层桥接模型拟合与独立验证协议

## 前置条件

输入固定为T038生成的`two_layer_bridge_observations_v1.csv`。拟合程序必须先读取`two_layer_bridge_admission_v1.json`，同时满足工作流通过、决策为`provisional_ready_for_identification`、准入记录的数据SHA-256与当前输入一致。任何一项不满足时禁止拟合。

## 模型与数据隔离

模型结构、参数边界和时间对齐沿用T024：由前一行双层状态与当前行实际灌水、太阳辐射、VPD预测当前行双层状态增量。6个`identification`循环用于有界最小二乘，3个`validation`循环只在参数固定后评价。

验证循环不得用于改变模型结构、特征、边界或判据。首次正式运行无论通过或失败都保留结果；失败时不进入双层控制器开发。

## 成功判据

软件和模型同时满足以下条件才允许向控制任务交接：

1. 输入再次通过T023质量闸门，辨识与验证循环不相交；
2. 两层有界求解收敛，参数满足冻结符号边界；
3. 两层单步预测相对持久性基线的技能值均不低于0.10；
4. 两层整循环预测相对常初值基线的技能值均不低于0；
5. 两层整循环绝对偏差均不超过0.01 m³/m³；
6. 全部滚动预测位于0.02至0.65 m³/m³。

正式结果记录输入、准入报告、配置和代码提交哈希。结果适用范围为独立合成双层对象的低阶模型拟合，不构成红壤实测模型证据。本任务不生成图。
