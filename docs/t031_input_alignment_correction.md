# T031 现场输入区间时间对齐修正

## 问题

现场CSV将每行灌水、流量和气象量定义为以该行时间戳结束的采样区间。T024模型辨识据此使用第`k`行区间输入预测第`k`行状态，但T027最初用第`k−1`行输入构造同一转移，造成模型准入的信息矩阵与实际辨识矩阵错开一个采样区间。

该问题不会改变合成弱激励样例需要补采的结论，但会改变信息量和预测不确定性的具体数值。在真实灌水为稀疏脉冲时，一步错位可能使准入矩阵评价错误的输入—响应关系，必须在过程噪声分解前修复。

## 统一规则

对同一循环内相邻观测`state[k−1] → state[k]`：

- 状态差使用第`k−1`行浅、深层水分；
- 实际灌水、太阳辐射、温度和相对湿度使用第`k`行；
- 每个循环首行仅为初始状态，不形成转移；
- 不允许跨循环连接；
- 辨识、信息准入和后续残差分解必须调用同一时间语义。

## 验证

新增定向测试，将3.25 mm脉冲只写入辨识循环第二行，要求它出现在该循环第一条状态转移中而不是第二条。原有验证循环隔离、141条转移和矩阵满秩测试继续保留。

修正后必须重新生成T027结构化结果、更新相关报告数字，并重新运行毕业设计证据审计。本任务不生成图形。
