# T036 双层辨识模型与MPC控制接口一致性审计

## 审计结论

当前模型链与控制链尚未闭合。T024—T027建立的是15 min时间步、10 cm和25 cm双状态、实际灌水量与太阳辐射/VPD输入的灰箱模型；T008—T010评价的是1 h时间步、单一根区状态、灌水命令与ET预测输入的MPC。T010能够支撑单层仿真中的控制适用性结论，但不能作为“T024辨识模型已经进入MPC”的证据。

更关键的是，T027对现有240行合成样例给出的决策为`collect_more_excitation`。按已经冻结的数据准入原则，该模型路径尚未取得`provisional_ready_for_identification`，因此不能为了论文连贯性绕过准入门，直接把T024参数装入正式双层MPC。

## 主要断点

### 1. 状态与目标不一致

双层模型分别预测浅层和深层含水率，现有MPC只接收一个水分状态并对单一区间计算亏缺和过湿代价。双层控制需要预先定义两层的目标区间、安全界限及相对权重，并说明规则基线使用浅层、深层、加权根区状态还是双阈值逻辑。

### 2. 时间尺度不一致

现场数据入口固定为15 min，现有控制试验按1 h运行。模型系数是逐步系数，不能在不变换的情况下跨时间步使用。后续双层闭环统一采用15 min控制步，再根据灌水设备最小脉冲确定控制时域和预测时域。

### 3. 灌水语义不一致

双层模型使用当前区间的实际灌水深，控制器决策输出的是未来命令灌水深。闭环预测必须包含命令到实际水量的执行映射；执行后用流量反馈更新下一时刻状态和审计记录。若直接把命令量当作实际量，会把灌水效率与流量误差隐含进模型系数。

### 4. 气象输入不一致

双层模型使用太阳辐射和VPD，现有MPC使用ET预测序列。后续可选择两条可审计路径：直接向MPC提供太阳辐射和温湿度预测，再计算VPD；或建立并冻结从气象到ET的转换模块。不能在实验后根据效果混换两类输入。

### 5. 虚拟对象独立性不足

T024合成序列与被辨识模型共享人为生成规律，适合验证辨识入口，不适合证明闭环鲁棒性。双层闭环需要独立的非线性虚拟对象，至少包含分层储水、浅深层交换、分层蒸散、非线性深层排水、执行效率和观测噪声；控制器只读取辨识所得模型和可用观测，不读取对象真值参数。

## 冻结补建顺序

1. **建立独立双层非线性虚拟对象。** 先通过水量平衡、边界和方向性测试，不接控制器。
2. **生成开发辨识数据。** 使用安全范围内变化的初始浅深水分梯度、灌水脉冲时刻与幅值以及天气日程。
3. **运行结构质量与信息准入。** 只有输出`provisional_ready_for_identification`时才拟合控制模型；若信息不足，调整开发采样设计，不使用锁定闭环场景。
4. **冻结双层模型与控制接口。** 固定15 min步长、气象预测字段、命令—实际灌水映射、两层目标与安全约束、预测时域和动作集合。
5. **开发集有限选择。** 同时标定双层规则基线和双层MPC，禁止读取锁定场景。
6. **锁定配对评价。** 两种控制器共享对象、扰动和观测噪声，联合报告浅层亏缺、深层亏缺、过湿、命令与实际灌水、排水和动作变化。
7. **绑定平台审计。** 每次运行记录数据、准入结果、模型、控制器、场景和代码提交哈希。

## 论文处理

在双层闭环完成前，第3章和第4章应明确为互补证据：第3章证明有限数据模型准入与辨识方法，第4章证明单层根区对象上的MPC冻结评价方法。不得写成“第3章辨识模型用于第4章MPC控制”。

完成上述闭环后，可在第4章新增“双层模型驱动的端到端验证”一节，并将现有单层结果保留为基准实验。双层结果必须使用新的开发集和锁定集，不能追溯改写T010分类。
